## Overview

YPPF Mini is the WeChat Mini Program client for a student platform developed for the school. It supports development and production builds for WeChat Mini Program, H5, and app targets.

## Interface

![Selected interfaces from the YPPF Mini WeChat Mini Program](/photos/yppf-mini-ui.jpg)

<small>Home, reservation, application center, and user profile interfaces.</small>

## Technology

- uni-app
- Vite
- UnoCSS
- Django REST framework backend

The frontend communicates with the YPPF backend API and can be developed through WeChat Developer Tools with hot reload support.

[View the source code on GitHub](https://github.com/Yuanpei-Intelligence/YPPF-mini/tree/main).
